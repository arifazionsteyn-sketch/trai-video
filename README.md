# TRAI · ролики

Короткие ролики про золото (Reels / Shorts / TikTok) на русском, английском и узбекском и промо «ноутбук» для сайта TRAI.
Код самого сайта здесь не хранится — ролики берут данные с сайта по ссылке.

- `video/gen.py` — сценарий, озвучка, кадры, отправка в Telegram. Запуск: каждый день в 08:00 (Ташкент) или изменить `video/run.json`.
- `video/promo.cjs` + `promo.html` — промо «ноутбук» (4K, 60 к/с). Запуск: изменить `video/promo.json`.
- Ключи — только в Settings → Secrets and variables → Actions.
